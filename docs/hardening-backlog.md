# 고도화 후보 목록

**목적**: 1단계에서 일부러 미룬 보안·견고성 지적을 한 곳에 모은다. 기능을 먼저 쓸 만하게 만들고 보안·견고성은 그 뒤에 고도화한다는 원칙(DEC-0106, 검토 기준 「1단계는 기능을 먼저 쓸 만하게 만든다」) 때문에 고치지 않은 것들이다.
**소유자·마지막 검토**: hanumoka · 2026-10-12
**읽는 사람**: PR을 쓰고 병합하는 AI, 고도화를 시작할 때의 소유자.

이 목록에 있는 것은 알려진 약점이다. 1단계 서버는 소유자 PC의 `127.0.0.1`에서만 받으므로 위험은 그 PC 안에 머문다. 이 판을 다른 곳에 설치해 밖으로 열지 않는다.

## 쓰는 방법

1. **더하기**: 검토 결과의 「고도화 후보」 칸에 오른 지적을 작성 AI가 병합 전에 이 표에 옮긴다. 번호는 `H-NN`으로 이어 붙이고 다시 쓰지 않는다.
2. **당기기**: 실제로 써 보다가 불편을 주는 후보는 그것만 앞으로 당겨 고친다. 「언제 당기나」 칸이 그 신호다. 지키는 선 셋에 닿는 것이 실제로 일어나면 바로 당긴다.
3. **닫기**: 고친 PR이 아직 병합 전이면 상태를 「고치는 중(#PR 번호, 병합 대기)」으로, 병합되면 「고침(#PR 번호)」으로 바꾼다. 줄은 지우지 않는다.
4. **전체 다시 보기**: 서버를 이 PC 밖으로 열기로 할 때, 또는 소유자가 정할 때 이 목록 전체를 다시 본다.
