## 검토와 수정

원문은 [공용 실행·자료 권한 독립 검토](../reviews/2026-10-18-work-preview-runtime-privacy-initial.md)에 보존했다. 이 문서는 작성자의 대응이며 독립 검토자의 재승인을 대신하지 않는다.

| 지적 | 수정 |
|---|---|
| R2 제한 검사가 다른 오류로 통과할 수 있음 | 합성 API 키를 명시하고 공용 실행 정책 때문에 거절했는지 검사. 그 정책을 제거한 별도 복사본에서는 시험이 실패함을 확인 |
| R3 자격 폐기 종료 코드 미검증 | HTTP 401을 주는 시험 서버로 CLI를 실행해 종료 78·요청 1회·로그에 기기 토큰 없음 확인 |
| R4·R5 정상 종료·종료 코드 설명 | systemd 예시에 `SuccessExitStatus=130`, CLI 주석에 종료 78 추가. 대상 Linux의 서비스 시작 시험은 별도 |
| P1 마스터 작업·실행에 복사된 비공개 자료 | 모든 원본의 현재 열람 권한을 목록 SQL과 개별 판정에 적용. 실행 후보와 실행 직전에도 실행자의 열람 권한 확인 |
| P2 받을 사람이 읽지 못하는 질문이 대기 상태로 남음 | 생성 전에 활성 구성원·상위 작업 열람을 확인하고 거절 사유 표시. 공유 범위는 자동 변경하지 않음 |
| P4 상태 카드 개수·계정 이력의 참조 | 숨긴 알림의 개수를 제외하고 계정 이력의 구조화된 실행 참조 검사. 매니저 작업 목록에도 원본 권한 적용 |
| P6 순환 탐색 상태 정리 | 참조 해석 중 예외가 나도 `finally`에서 탐색 표식을 제거 |
| H-45·H-46·H-47·H-56 상태 불일치 | 검증된 시험판 브랜치와 병합 전 상태를 고도화 목록에 표시 |

첫 관리 기능 검토의 기기 승인·발급 경합은 `a193fdc`, 수신자별 알림과 미전달 복구는 `6b320d4`에 있다. OS별 프로세스 종료 범위도 `a193fdc` 문서에서 구분했다.

## 재현과 결과

전제조건은 Java 25와 Docker의 PostgreSQL 17 시험 환경이다. 운영 DB를 지정하지 않는다. Go 검사는 Go 1.27과 합성 실행기를 사용한다.

1. `apps/server`에서 `./gradlew test`를 실행했다. 304건 통과, 실패·오류·건너뜀 0이었다. 최초 전체 실행은 실제 구성원이 아닌 가상의 질문 수신자 때문에 1건 실패했고, 시험 자료를 실제 구성원으로 고친 뒤 다시 통과했다.
2. 감사 사건 두 개의 트랜잭션 시각과 UUIDv7 밀리초가 같을 수 있어, 등록 시험에서 둘 사이의 순서를 전제하지 않도록 고쳤다. 마지막 시험 정리 뒤 `./gradlew test --tests '*AuditApiTests' --tests '*PermissionScopeTests' bootJar`로 17건과 JAR 빌드를 통과했다. 마스터 원본의 다섯 공유 범위·여섯 사용자 관계, 목록·상세·실행·내보내기, 질문 거절 후 작업 상태 보존을 검사한다.
3. `apps/agent`에서 `go test ./internal/agent ./cmd/zm-baton -run ServerWorker -count=1 -v`를 Linux에서 통과했다. Windows용 시험 바이너리로 같은 서버 모드·종료 78 시험과 실제 하위 프로세스 기기 폐기 시험을 통과했다.
4. 별도 임시 복사본에서 `ServerWorker` 정책 조건만 제거하면 거절 시험이 실패했다. 자격이 없다는 다른 오류로 통과하는 거짓 성공을 방지한다. 원본 코드는 그 실험으로 바꾸지 않았다.
5. 실패하면 원본 권한·실행 정책 검사를 약하게 하지 않고 시험 자료와 구현의 차이를 확인한다. 새 정책·병합·운영 반영은 최종 사용자 확인 대상이다.

## 실제 실행의 범위

본인 구독과 합성 저장소의 실제 Claude Code 실행으로 웹 요청 후 백그라운드 제출, 실행 취소·기존 세션 재개, API 재시작 후 같은 실행 번호로 결과 저장을 확인했다. 작업자 강제 종료 뒤에는 임대와 재연결 유예가 지나 `lost`가 된 것을 확인하고 다시 맡겼다. 종료 확인이 없는 옛 작업 트리를 재사용하지 않고 이전 브랜치에서 새 작업 트리를 만들어 제출했다.

이 시험은 Windows의 본인 작업이다. 조직 API 호출, Linux systemd 실제 설치, Linux/macOS 하위 프로세스 종료의 검증으로 계산하지 않는다. 조직 API 자격은 소유자가 나중에 준비해 최종 확인하기로 했다.

삭제된 원본의 감사 행을 숨기는 동작과 대규모 이력의 처리량은 [자료 열람 시험판의 한계](privacy-preview.md#현재-한계)에 남긴다. 독립 재검토와 최종 사용자 확인은 아직 남아 있다.
