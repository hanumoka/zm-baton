# 여러 사용자의 자료 열람 — 시험판 보완

**목적**: 연결된 기록이나 운영 화면을 통해 비공개 업무 내용이 드러나는 것을 막는다.
**대상·소유자**: 서버 관리자·조직 구성원 / hanumoka.
**마지막 검토**: 2026-10-18.
**상태**: 최종 확인 전의 격리 구현. 조직 운영자·서버 관리자에게 개인 자료 열람 권한을 추가하지 않는다.

## 적용하는 범위

- 문서·결정 상세의 연결 작업·결정 목록과 AI 계정의 최근 실행 목록에는 보는 사람이 읽을 수 있는 업무만 표시한다.
- 질문·검토 요청은 그 자체의 권한과 상위 작업의 권한을 모두 만족해야 열린다. 질문을 전달받았다는 이유로 개인 작업을 열지는 못한다.
- 첫 화면에서도 상위 작업과 알림 근거의 현재 열람 권한을 확인한다. 공유 범위를 좁힌 뒤 남은 옛 알림도 숨긴다.
- 감사 기록의 목록·개별 조회·분류별 개수에 같은 제한을 적용한다. 다른 기록의 비공개 내용을 복사한 구조화된 근거도 검사한다.
- 모순 알림과 마스터 검사에는 비교한 문서·결정과 연결 실행의 권한을 적용한다. 일부만 허용되면 비교 결과 전체를 숨긴다.
- 자동 모순 검사의 작업 제목·실행 지시문·결과·계정 이력에도 모든 원본의 현재 권한을 적용한다. 이미 끝난 검사도 원본을 비공개로 바꾸면 함께 숨긴다. 목록과 상세, 매니저 기록, 상태 카드와 내보내기에 같은 조건을 쓴다.
- 조직 소유자의 실행기가 읽을 수 없는 원본으로 자동 검사를 시작하지 않는다. 비교 후보도 그 실행자의 권한 안에서 고른다. 요청 후 실행 권리 청구 전에 원본 권한이 좁아진 경우 실행을 취소한다. 실행기에 이미 전달된 내용까지 회수하는 기능은 없다.
- 질문을 받을 사람이 상위 작업을 볼 수 없거나 활동 중인 구성원이 아니면 질문 생성을 거절한다. `waiting_answer`를 남기지 않고 공유 범위와 역할을 확인하라는 이유를 표시한다.
- 운영자의 내보내기는 `personal`뿐 아니라 `restricted`·`team`을 포함한 현재 열람 범위를 따른다. 숨긴 자료에 연결된 문서판·실행·이벤트·승인·질문·감사 기록을 함께 제외한다.
- 남의 첫 화면 항목과 공유하지 않은 과거 세션 요약은 내보내지 않는다. 나중에 공개한 세션에서도 예전 비공개 요약은 숨긴다.

질문이나 검토를 다른 사람에게 맡기려면 먼저 그 사람이 상위 작업을 읽을 수 있도록 공유해야 한다.
이 임시 정책과 알림을 숨기는 동작은 최종 사용자 확인 대상이다. 공유 범위를 자동으로 넓히지 않는다.

## 내보내기와 복구

내보내기는 사용자가 읽을 수 있는 자료를 담는 JSON이다. 전체 DB 백업과 다르다.
연결된 비공개 자료가 하나라도 있으면 종속 행 전체를 제외하므로 부분 실행이나 부분 승인을 완전한 기록처럼 내놓지 않는다.
서버 관리자 설정, 로그인 자격, 개인 매니저 메모 등 제외 항목은 내보내기의 `provenance.not_exported`에 적는다.
설치 전체를 복원할 때는 PostgreSQL 백업을 사용한다.

## 확인 절차

전제조건은 Docker의 PostgreSQL 시험 환경과 Java 25다. 운영 DB를 시험 대상으로 지정하지 않는다.

1. `apps/server`에서 `./gradlew test --tests '*PermissionScopeTests' --tests '*ExportTests' --tests '*AuditScreenApiTests' --tests '*MasterCheckTests' --tests '*ReviewTests'`를 실행한다.
2. 소유자·운영자·작업 책임자·프로젝트 구성원·팀 구성원·그 밖의 구성원을 만들고 모든 공유 범위를 비교하는 시험이 통과하는지 확인한다.
3. 비공개 작업의 질문·검토 수신자에게 상세와 첫 화면 항목이 보이지 않고, 작업을 명시적으로 공유한 뒤 보이는지 확인한다.
4. 비공개 실행의 지시·결과와 문서판 본문이 다른 사람의 내보내기에서 빠지는지 확인한다.
5. 실패하면 해당 API를 공유 서버에 적용하지 않고 시험판 브랜치에서 수정한다.

## 현재 한계

- 검사 대상은 구조화된 ID 참조다. 사람이 다른 공개 문서의 자유문에 비공개 내용을 직접 복사한 경우를 자동으로 판정하지 않는다.
- 삭제된 자료의 열람 권한을 재구성할 수 없으면 해당 자료를 가리키는 감사 행을 숨긴다. 원본 감사 행은 삭제하지 않는다.
- 감사 목록은 허용된 행을 채울 때까지 검사하며, 분류별 개수는 조건에 맞는 기록을 검사한다. 작은 설치를 위한 구현이며 대규모 이력의 처리량은 측정하지 않았다.
- 모순 목록은 기존 최근 200건·최근 검사 수 제한 안에서 권한을 적용하므로 숨긴 행만큼 표시 건수가 줄 수 있다.
